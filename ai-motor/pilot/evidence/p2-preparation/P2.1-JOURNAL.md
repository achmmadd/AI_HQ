# P2.1-JOURNAL — durable synthetic outcome-review (lokaal, niet live)

```text
P2_1_STATUS=CODE_LOCAL
BRANCH=pilot/p2.0-motor-kiosk
BASE_HEAD=67a275a
TEST_COUNTS=295 pass / 0 fail / 1 skip
JOURNAL=/p2-review/outcome-review.jsonl
VOLUME=motor-pilot_pilot-p2-review (compose only; not created live)
REAL_CONTEXT_USED=no
EXTERNAL_EFFECTS=no
PUBLIC_INGRESS=no
MASTER_MERGE=no
DEPLOYED=no
PUSHED=no
SQLITE=no
POSTGRES_MIGRATION=no
P0_UNCHANGED=yes
```

Append-only JSONL voor synthetische `ws-motor`-templates. Geen Kernel, geen
P0-store, geen `pilot-context`, geen NUC-schrijfpad. Reconstructie bij
service-start uit het journal; vrije draftbody is geweigerd.

```text
event_id
type                  draft_created | review_submitted | review_decided
workspace_id          ws-motor
actor_stable_id       laptop WhoIs n…
draft_id              draft-p21-<template>-…
from_status / to_status
synthetic_template_id tpl-p21-review-reply | tpl-p21-observation-note
draft_body_digest     sha256 van de vaste templatebody
occurred_at
```

Dubbel `event_id` = no-op. Eindstatus `approved|rejected` onomkeerbaar.
`approved` blijft publish/mail/payment/device DENY. NUC-id is nooit actor.

Private-context: default `synthetic`. `body.context` → 400.
Private-vlag zonder bron → `private_declared_absent`.
`CONTEXT_FILE` / Qdrant / connector → `private_blocked` zonder file-read.

Activatie van volume + recreate is een apart letterlijk commando:
`ACTIVATE P2.1`. Deze commit wijzigt geen `.env`, ACL, Hetzner of NUC.
