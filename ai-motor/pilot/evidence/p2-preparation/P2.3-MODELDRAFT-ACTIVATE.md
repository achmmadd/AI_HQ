## Wat live gezet is

P2.3 staat live op Hetzner motor2 op SHA `27a94c6`
(`27a94c60118944f156ad1a24a3fe4dc0bf50cea9`). Alleen `motor-p2-ui` is
gerecreëerd (`6e762e46419b` → `6e8c68c1b5e9`). Overlay en `.env` zijn
niet aangeraakt. P0 is ongewijzigd. Geen `docker compose down`. Op
motor2 is geen `git config` gezet (identity daar unset); dit
activate-bewijs wordt op RTX gecommit.

template-body en geen P0-body in de UI of view-JSON. Geen nieuwe
HTTP-route, geen nieuw journal-event-type.

## Live-meting (operator op motor2 — geen RTX-HTML)

Deze RTX kan `:4420` HTML/JSON-view **niet** hercurl’en: GET `/motor`
en GET `/api/motor/view` geven `403 node_not_allowed`. Laptop-WhoIs op
`:4420` is **niet** hercurl’d (`unknown, meten door eigenaar`).
Titel+digest is op motor2 gemeten met `createP2MotorServer`-handlers
tegen het live `/p2-review`-journal. Motor2’s eigen GET op `:4420`
blijft `403`.

| Check | Resultaat | Bron |
|---|---|---|
| GET `:4420/motor/health` | 200 `{"ok":true}` | operator motor2; RTX herbevestigd 200 |
| GET `/motor` titel+digest, geen template/P0-body | ja — `data-title="1"` + `data-digest="sha256:…"`; journal open 24 / in review 0 / done 1 | operator: handlers vs live journal |
| GET `/api/motor/view` drafts | titel+digest; keys `id,title,digest,state,status`; geen `body` | operator: handlers vs live journal |
| GET schrijft journal | nee — SHA nog `4d9cc5c5…`, 27 regels | operator motor2 |
| P0 `:4400` | 200 `{"ok":true,"model":true}`; listen `100.97.30.22:4400` | operator motor2; RTX herbevestigd 200 |
| Vreemde host | 403 `node_not_allowed` | operator motor2; RTX `/motor` + `/view` 403 |
| Laptop WhoIs `:4420` | unknown, niet hercurl’d | — |
