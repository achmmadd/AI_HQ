# Motor AI — versiegeschiedenis (transparant)

Dit bestand is een **handmatige** changelog voor operators en validatie. Bij elke release:

1. Zet `NEXT_PUBLIC_VERSION` (bijv. `1.2.0`) in de build-/PM2-omgeving.
2. Voeg hier een regel toe met datum en korte bullets (gebruikersgericht).

## Sjabloon

### YYYY-MM-DD — vX.Y.Z

- Wat is er nieuw / verbeterd voor gebruikers.
- Bekende beperkingen (bijv. deploy vereist GitHub + Vercel tokens).
