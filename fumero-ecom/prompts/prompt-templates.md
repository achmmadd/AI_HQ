# Flair AI Prompt Templates — Per Productcategorie

Gebruik deze prompts in Flair AI voor consistente, professionele productbeelden per categorie.

---

## 🔑 Prompt Structuur

```
[OMGEVING], [VERLICHTING], [STIJL], product photography, ultra realistic, 8k, no text
```

**Altijd toevoegen aan elk prompt:**
```
, product photography, ultra realistic, 8k, no text, no watermark, commercial photography
```

**Vermijd altijd:**
- `people`, `hands`, `faces` (tenzij lifestyle prompt)
- `text`, `logo`, `brand name`
- `cartoon`, `illustration`, `painting` (tenzij bewust gekozen)

## 🔧 Prompt Modifiers — Snelle Aanpassingen

Voeg toe aan elk prompt voor specifieke effecten:

| Effect | Modifier |
|--------|---------|
| Meer diepte | `, shallow depth of field, f/1.8 lens` |
| Luxe gevoel | `, luxury editorial style, premium brand aesthetic` |
| Zomer sfeer | `, summer vibes, warm golden sunlight` |
| Winter/feest | `, winter festive, cozy christmas atmosphere` |
| Minimalisme | `, minimal clean white background, studio lighting` |
| Macro detail | `, extreme macro photography, fine texture detail` |
| Lifestyle | `, lifestyle photography, real-life setting` |
| Trending | `, trending on instagram, social media aesthetic` |

---

## 💾 Prompt Opslaan in Flair AI

1. Genereer een goed resultaat met prompt
2. Klik **"Save Prompt"** → geef naam: `{categorie}-{stijl}`
   - Bijv: `vapes-dark-forest`, `gummies-tropical-summer`
3. Herbruik via **"Saved Prompts"** voor consistentie
